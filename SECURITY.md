# Security policy

This project is an educational collection of scientific Python programs. It has
no network, authentication, or data-handling components, so its security surface
is small. Nonetheless, we take the integrity of the code seriously.

## Supported version

The latest release on the `main` branch is the supported version.

| Version | Supported |
|---|---|
| 1.0.x | :white_check_mark: |

## Reporting a vulnerability or a serious defect

For anything with a security dimension &mdash; for example a dependency advisory
that affects the recommended versions, or a defect that could cause a program to
write outside its own directory &mdash; please **do not** open a public issue.
Instead, report it privately:

- Use GitHub's **[Report a vulnerability](https://github.com/ileaof/statistical-thermodynamics-computation-verification/security/advisories/new)**
  (Security → Advisories), or
- email the maintainer at **ileaof@gmail.com** with the details and, if possible,
  a way to reproduce.

You can expect an acknowledgement within a few days. Once a fix is prepared, it
will be released and the report credited (unless you prefer to remain anonymous).

## Ordinary bugs

For non-security bugs &mdash; a failing example, a wrong number, a typo &mdash;
please open a regular [issue](https://github.com/ileaof/statistical-thermodynamics-computation-verification/issues).
